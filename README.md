# Telepath

Telegram storage as a folder in Finder — for macOS 14 and later, Apple silicon.

- **Site:** https://telepath.alienminds.net/
- **Download:** [latest release](https://github.com/sergey-lee/telepath/releases/latest)
- **Support:** [issues](https://github.com/sergey-lee/telepath/issues)

This repository holds the site and the update feed. The application source
is not public.

## What is in here

| Path | Purpose |
|---|---|
| `index.html` | the site, one self-contained file |
| `appcast.xml` | update feed read by the app itself |
| `CNAME` | custom domain, once there is one |

Disk images are attached to [Releases](https://github.com/sergey-lee/telepath/releases),
not stored in the repository: Pages is not meant for serving binaries.
